# Saved Searches

## Goal
Users can save a product search and receive an alert when a matching item is listed.

## Requirements
- A signed-in user can save a search query with at least one keyword.
- The user can choose an alert frequency of immediate, daily, or weekly. Daily is the default.
- The system sends alerts only for new matching items after the saved search is created.
- A user can pause, resume, rename, and delete a saved search.
- Deleted saved searches must not send any further alerts.

## Out of scope
- Users cannot share saved searches with other users in this release.
